# Phase 8 – Project Demonstration

## 1. Demonstration Overview

The final demonstration presents the working PocketSmart AI web application and explains its main features and workflow.

## 2. Demonstration Flow

The demonstration will cover the following steps:

1. Launch the PocketSmart AI application.
2. Display the landing page.
3. Register a new user account.
4. Login to the application.
5. Open the dashboard.
6. Select a planning category.
7. Enter the required budget and preferences.
8. Generate the recommendation plan.
9. Display the recommended items and budget breakdown.
10. Open recommendation history.
11. Display previously generated plans.

## 3. Features Demonstrated

The demonstration will show:

- User Authentication
- Dashboard
- Home Interior Planner
- Party Planner
- Jewelry Planner
- Budget Planning
- AI-assisted Recommendations
- Budget Breakdown
- Recommendation History
