# Phase 7 – Project Documentation

## 1. Project Title

PocketSmart AI – Smart Budget & Recommendation Assistant

## 2. Project Description

PocketSmart AI is an AI-powered web application designed to help users create budget-aware plans and receive suitable recommendations based on their requirements.

The application provides different planning modules and combines budgeting, recommendation services and AI assistance in a single platform.

## 3. Main Features

- User Registration
- User Login
- Session-based Authentication
- Dashboard
- Home Interior Planner
- Party Planner
- Jewelry Planner
- Budget-based Planning
- AI-assisted Recommendations
- Budget Breakdown
- Recommendation History
- Responsive Web Interface
