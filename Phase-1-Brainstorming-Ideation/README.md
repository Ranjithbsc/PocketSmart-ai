# Phase 1 – Brainstorming & Ideation

## Project Title
PocketSmart AI – Smart Budget & Recommendation Assistant

## 1. Problem Identification

Many people find it difficult to plan their budget while purchasing products or arranging events. They may have a fixed budget but are unsure how to distribute it among different requirements.

Traditional planning requires manually searching for products, comparing prices, and preparing a budget. This can be time-consuming and confusing.

## 2. Proposed Idea

PocketSmart AI is an AI-powered budget planning and recommendation web application.

The system allows users to select a planning category and enter their requirements and budget. Based on the provided information, the application generates suitable recommendations and a budget breakdown.

## 3. Main Planning Categories

- Home Interior Planning
- Party Planning
- Jewelry Planning

## 4. Key Idea

The main idea is to combine:

- User requirements
- Available budget
- Product/service categories
- AI-based recommendations
- Budget allocation

to provide a simple and personalized planning experience.

## 5. Target Users

- Students
- Families
- Individuals planning purchases
- Users with a fixed budget
- Users who need quick recommendations

## 6. Expected Outcome

The proposed system should help users:

- Plan within their available budget
- Understand budget allocation
- Get relevant recommendations
- Reduce manual searching
- Save time during planning

## 7. Initial Technology Idea

The project is planned as a web-based application using:

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini AI

## 8. Ideation Summary

PocketSmart AI was proposed as a smart planning assistant that combines budgeting and AI recommendations in a single web application.

This phase establishes the basic problem, proposed solution, target users, major features, and technology direction for the project.
